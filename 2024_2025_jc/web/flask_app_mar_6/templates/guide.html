HTML Elements Guide

A basic guide demonstrating various HTML elements.

Text Elements

This is a paragraph.

This is bold text. - Use <b>bolded text</b>

This is italic text. - Use <em>italic text</em>

This is underlined text. - Use <u>underlined text</u>

This is highlighted text. - Use <mark>highlighted text</mark>

This is small text. - Use <small>small text</small>

Headings

Use different levels of headings:

<h1>Heading 1</h1>

Heading 1

<h2>Heading 2</h2>

Heading 2

<h3>Heading 3</h3>

Heading 3

Lists

Unordered List

Use <ul> for unordered lists:

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
  • Item 1
  • Item 2

Ordered List

Use <ol> for ordered lists:

<ol>
  <li>First item</li>
  <li>Second item</li>
</ol>
  1. First item
  2. Second item

Links and Images

Use <a href="URL">link text</a> for links:

This is a link

Use <img src="image.jpg" alt="description"> for images:

Tables

Use <table> for tables:

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>John</td>
    <td>25</td>
  </tr>
</table>
Name Age
John 25

Forms

Use <form> for user input:

<form>
  <input type="text" name="name">
  <input type="submit" value="Submit">
</form>




Media Elements

Use <audio> for audio:

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>

Use <video> for videos:

<video controls>
  <source src="video.mp4" type="video/mp4">
</video>
