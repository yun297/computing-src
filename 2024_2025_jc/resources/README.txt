This all-in-one installer for H2 Computing includes the following software:

1. Python 3.7.7, with:
    * Flask 2.2.5
    * PyMongo 3.13.0
    * Jupyter Notebook 6.5.6
    * TensorFlow 2.11.0
    * Keras 2.11.0
    * Pandas 1.3.5
    * Matplotlib 3.5.3
2. DB Browser for SQLite 3.10.1
3. Notepad++ 7.5.4
4. MongoDB Community Server 3.4.9

To install, right-click `install.cmd` and `Run as administrator`.
